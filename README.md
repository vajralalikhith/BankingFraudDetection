# 🛡️ Banking Transaction Fraud Detection

A machine learning project that detects potentially fraudulent banking
transactions using Python and a Random Forest classifier.

## 🛠️ Technologies Used

- Python
- Scikit-learn
- Random Forest
- Streamlit
- MySQL / XAMPP
- Pandas

## 📊 Model Information

- Algorithm: Random Forest
- Input features: 30
- F1 Score: 0.839
- Dataset: 284,807 transactions

## ⚠️ Disclaimer

This project is intended for academic demonstration and is not designed
to make real-world banking decisions.
